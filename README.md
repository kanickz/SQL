# SQL Server Database Assignment

## 📌 Project Overview

This project contains SQL Server queries and database operations performed using SQL Server Management Studio (SSMS).

The assignment works with customer, salesman, orders, and sales data to demonstrate fundamental and intermediate SQL concepts.

## 🎯 Objectives

The main objective of this project is to practice SQL queries and understand how relational databases can be queried, modified, and structured using SQL Server.

## 🛠️ Technologies Used

- Microsoft SQL Server
- SQL Server Management Studio (SSMS)
- T-SQL

## 📚 Concepts Covered

### Data Retrieval
- SELECT
- WHERE
- TOP
- LIKE
- BETWEEN
- Column selection

### Data Manipulation
- INSERT
- ALTER TABLE

### Aggregate Functions
- SUM()
- GROUP BY

### Joins
- INNER JOIN
- RIGHT JOIN

### Set Operators
- UNION
- UNION ALL

### Database Constraints
- PRIMARY KEY
- FOREIGN KEY
- DEFAULT
- NOT NULL

### Other SQL Operations
- EXEC sp_help
- Table creation
- Working with multiple tables
- Filtering and sorting data

## 🗂️ Database Tables

The project works with tables such as:

- Customer
- Salesman
- Orders
- Sales

These tables contain information related to customers, salesmen, orders, products, quantities, prices, and purchase amounts.

## 🔍 Key Operations

Some of the operations performed in this project include:

- Retrieving customer and salesman information
- Filtering customers based on city and purchase amount
- Finding total sales using aggregate functions
- Joining customer, salesman, and orders tables
- Combining Salesman IDs using UNION and UNION ALL
- Creating primary key and foreign key constraints
- Adding default values to columns
- Applying NOT NULL constraints

## 📁 Project File

- `SQLQueryMandatoryassignment1.sql` – Contains all SQL queries and database operations performed for the assignment.

## ▶️ How to Run

1. Install Microsoft SQL Server and SQL Server Management Studio (SSMS).
2. Open the `.sql` file in SSMS.
3. Make sure the required database and tables are available.
4. Execute the queries sequentially.
5. View the results in the Results window.
